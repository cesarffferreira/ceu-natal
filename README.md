# Céu Natal

Site de mapa astral (carta natal tropical): planetas, casas, aspectos, céu de agora e guia de signos.

Página única (`index.html`), cálculos com [astronomy-engine](https://github.com/cosinekitty/astronomy).

## Publicar no GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.
